# test

Generated by `webuse create`.

[Webuse on GitHub](https://github.com/lexiforest/webuse)

Project settings and named spiders live in `webuse.yaml`. The Books spider's
crawl rules live in `spiders/books.yaml`.

## Generate a Spider

```bash
webuse gen books https://books.toscrape.com/
webuse crawl --spider books -o books.jsonl
```

## Fetch

To test a single URL:

```bash
webuse fetch https://books.toscrape.com/ --css "article.product_pod h3 a" --attr title --all
```

## Items

`spiders/books.py` contains the `BookItem` model and `CleanBookPipeline` alongside
the spider class.
Configure item processing in each spider's `pipelines` section, or its
Python `pipelines` attribute.
