Addtionally to the open source release, we also offer a cloud hosted version at:
https://impersonate.pro/webuse.

## Cloud Services

Compared to local open source crawler management, our cloud product offers:

* (Residential) proxies, with rotation, geographic routing, and sticky sessions;
* CAPTCHA solving;
* Browser rendering and interaction;
* Automatic HTML-to-Markdown content extraction;
* Monitoring and streaming logs;
* Diagnosis from logs and failed responses;
* Data sanity checks and alerts;
* Isolated environment for the harness and crawler agent.

Most importantly, all of them have been **integrated with our cloud harness**, so the AI
builder already knows when and how to use them. You don't need to find vendors and
manage all the API keys and services by yourself. Just say what you want to scrape,
and the data will be delivered.

## Are there any vendor-lockin risk?

No, webuse cloud use the same execution model after the local process manager.

You can download your code at anytime and run with the open source framework without
changes.
