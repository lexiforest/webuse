# webuse GUI

SolidStart app for generating `webuse fetch` and `webuse crawl` task configs.

## Run

```bash
pnpm install
pnpm dev
```

If `pnpm` is not installed locally:

```bash
npx --yes pnpm install
npx --yes pnpm dev
```

The dev server prints a local URL, usually `http://127.0.0.1:5173/`.

## Build

```bash
pnpm build
```
